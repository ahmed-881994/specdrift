About SpecDrift

SpecDrift is a focused developer tool for comparing two Swagger or OpenAPI specifications and identifying contract changes that can affect API consumers. It is built for teams that need a fast compatibility check before merging, releasing, or documenting an API change.

The comparison engine classifies differences as breaking, potentially breaking, or non-breaking. That makes it easier to decide whether a change needs a migration guide, a new API version, additional client testing, or a simple documentation update.

What Makes It Useful

  • It understands common Swagger 2.0 and OpenAPI 3.x structures.
  • It checks endpoints, methods, parameters, request bodies, responses, schemas, and enums.
  • It gives plain-language results instead of a raw text diff.
  • It does not require an account or store uploaded specifications.

Project Transparency

SpecDrift is open source. You can review the implementation, report issues, or suggest improvements in the GitHub repository.

New to API compatibility reviews? Start with the How SpecDrift Works guide, read the OpenAPI breaking changes guide, or compare two specs on the SpecDrift comparison page.
