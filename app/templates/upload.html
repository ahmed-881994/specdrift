Compare API Specifications

SpecDrift helps you identify breaking changes between two versions of your API specification. Upload or paste your Swagger 2.0 or OpenAPI 3.0 specifications (JSON or YAML format) to get started.

📤 Step 1: Upload Your Specs

Choose to either upload files or paste your API specifications directly into the text areas below. Supports both JSON and YAML formats.

🔍 Step 2: Compare

Click "Compare Specs" and our tool will analyze both specifications, identifying all changes and categorizing them by severity.

📊 Step 3: Review Results

See a detailed breakdown of breaking changes, potentially breaking changes, and safe non-breaking changes with clear explanations.

What Changes Does SpecDrift Detect?

  • Breaking Changes: Removed endpoints, deleted required parameters, changed response types, removed enum values
  • Potentially Breaking: Modified status codes, changed parameter formats, updated authentication requirements
  • Non-Breaking Changes: New endpoints, added optional parameters, expanded enum values, new response properties

Tips for Best Results

  • Ensure your specifications are valid Swagger 2.0 or OpenAPI 3.0 documents
  • Use the "Beautify" button to format your specs for easier review
  • Compare sequential versions of your API to track changes over time
  • Review all breaking changes before deploying API updates to production
