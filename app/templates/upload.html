What the engine detects

BREAKING

Removed contract surface

Removed endpoints, required parameters, response fields, enum values, or incompatible type changes.

RISKY

Review-worthy changes

Status code changes, stricter validation, auth changes, format changes, and ambiguous schema updates.

SAFE

Additive improvements

New endpoints, optional parameters, response additions, expanded capabilities, and documentation updates.
